## Featured Projects

### 1. Cowrie SSH Honeypot & Splunk SOC Lab

**Technologies:** Cowrie, Splunk Enterprise, Splunk Universal Forwarder, Ubuntu Server, SPL

[View Project](./cowrie-honeypot/)

Deployed an SSH honeypot to observe and analyze suspicious authentication attempts and attacker interactions. Integrated Cowrie with Splunk to collect, index, search, and visualize security events.

**Key Contributions:**
- Deployed and configured a Cowrie SSH honeypot on Ubuntu Server.
- Configured Splunk Universal Forwarder to transmit structured JSON logs.
- Ingested and analyzed honeypot events using Splunk Enterprise.
- Developed SPL searches to examine authentication attempts and suspicious commands.
- Created dashboards and alerts to monitor suspicious activity.
- Documented investigation findings and distinguished controlled testing activity from externally generated events.

**Skills Demonstrated:** SIEM administration, log analysis, security monitoring, SPL, Linux administration, and threat investigation.

### 2. Phishing Email Analysis & Investigation

**Technologies:** Email Header Analysis, IOC Analysis, Security Investigation

[View Project](./phishing-email-analysis/)

Conducted five phishing and suspicious email investigations to evaluate potential threats, examine sender information, identify indicators of compromise, and document appropriate response recommendations.

**Key Contributions:**
- Examined email headers and sender authentication information.
- Evaluated suspicious sender addresses and URLs.
- Identified and documented potential indicators of compromise.
- Assessed suspicious activity and differentiated confirmed phishing indicators from unverified findings.
- Documented investigation findings and recommended remediation steps.
- Followed safe handling practices when examining suspicious email content.

**Skills Demonstrated:** Email security, phishing detection, threat analysis, IOC identification, analytical reasoning, and incident documentation.
